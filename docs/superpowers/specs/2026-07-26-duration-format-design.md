# GenImage 计时格式设计

## 目标

前端所有生成耗时统一使用秒作为单位，并固定显示两位小数。例如，`500 ms` 显示为 `0.50 秒`，`14050 ms` 显示为 `14.05 秒`。

## 范围

- 修改 `frontend/src/App.vue` 中现有的 `formatDuration` 格式化入口。
- 生成中的实时计时和生成结果卡片共用同一格式。
- 后端继续返回毫秒数，不修改 API 或数据库字段。

## 格式规则

- 有效毫秒值统一除以 `1000`，再使用 `toFixed(2)` 固定两位小数。
- `0` 显示为 `0.00 秒`。
- 不足一秒的值不再显示 `ms`。
- `null` 或 `undefined` 继续显示“计时不可用”。

## 测试

在前端组件测试中覆盖：

- `500 ms` 显示为 `0.50 秒`。
- `14050 ms` 显示为 `14.05 秒`。
- 页面不再出现毫秒单位。
