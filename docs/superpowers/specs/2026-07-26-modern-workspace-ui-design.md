# GenImage 现代化工作台 UI 设计

## 目标

将现有高饱和黄色、粗黑边框和硬阴影界面调整为冷白灰与蓝色强调的现代扁平化工作台。保留“左侧参数、中央画布、底部创作区”的核心工作流，同时降低低频配置和历史记录对主界面的占用。

本次同时修正全屏图片预览的视觉问题：取消深色大面积背景，使用明确的视口尺寸约束，保证图片底部始终完整可见。

## 信息结构

### 顶部栏

顶部栏保留 GenImage 品牌和服务配置状态。右侧增加历史记录按钮，按钮显示历史图标、文字和记录数量。点击按钮后从右侧打开历史抽屉。

### 左侧参数栏

左栏只承载生成相关配置：

- 接口配置折叠区
- 模型名称
- 细节级别
- 生成数量

接口配置默认折叠，折叠标题显示“接口配置”和“已配置/未配置”状态。展开后显示 API Key、只读 Base URL 和保存配置按钮。提供商名称不在界面中展示。

### 中央工作区

中央区域继续包含作品画布、生成状态、分析结果和生成图片。底部创作区继续固定在中央区域底部，参考图片位于提示词输入框上方。

### 历史抽屉

历史记录从左栏移除，改为覆盖式右侧抽屉。打开抽屉不会改变主画布宽度。抽屉包含标题、记录数量、关闭按钮和可滚动历史列表。

点击历史记录后加载记录到中央画布，并关闭抽屉。抽屉支持以下关闭方式：

- 点击右上角关闭按钮
- 点击页面遮罩
- 按 `Esc`

## 左栏宽度调整

桌面端在左栏和中央工作区之间提供窄拖拽手柄：

- 默认宽度为 `320px`
- 最小宽度为 `280px`
- 最大宽度为 `480px`
- 拖拽范围同时受当前视口可用宽度限制，中央工作区必须保留可用空间
- 手柄平时弱化，悬停、键盘聚焦或拖动时使用蓝色强调
- 手柄提供可访问名称和分隔条语义

本阶段不持久化用户调整后的宽度；刷新页面后恢复默认值。移动端隐藏拖拽手柄，左栏恢复为全宽文档流。

## 视觉语言

- 页面背景使用冷白灰，内容面板使用白色或接近白色。
- 主文字使用深灰，辅助文字使用中灰。
- 主操作、选中状态、焦点和配置成功状态使用蓝色系。
- 错误状态保留克制的红色。
- 控件和面板使用不超过 `8px` 的小圆角。
- 仅在输入框、区域分隔和抽屉边界保留必要的 `1px` 浅灰线条。
- 移除粗黑边框、硬阴影、大面积黄色背景和装饰性方块。
- 抽屉和全屏预览可使用轻微阴影表达层级，不使用渐变。

## 全屏图片预览

点击生成图片打开覆盖视口的预览层。预览层使用浅灰半透明背景，不再使用黑色背景。

图片尺寸同时受以下约束：

- `max-width: calc(100vw - 32px)`
- `max-height: calc(100dvh - 32px)`
- 使用 `object-fit: contain`

桌面端可增加少量安全间距，但必须通过显式 `vw` 和 `dvh` 计算保证图片边界不超过视口。关闭按钮固定在右上角。点击遮罩、关闭按钮或按 `Esc` 均关闭预览。

## 响应式行为

桌面端使用可调宽左栏和中央工作区。历史抽屉覆盖在右侧。

窄屏下改为单列文档流，顺序保持：

1. 图片参数与折叠接口配置
2. 作品画布
3. 参考图片
4. 提示词与生成操作

历史抽屉在移动端占据大部分或全部视口宽度。页面不得产生横向滚动，抽屉和全屏预览中的文字、图片和按钮不得超出视口。

## 状态与交互

- 接口配置默认折叠，配置状态来自现有 `api_key_configured` 数据。
- 保存接口配置继续使用现有设置 API，不改变 Base URL 只读行为。
- 打开历史抽屉不触发额外请求，继续使用页面初始化时加载的历史列表。
- 点击历史记录继续使用现有详情接口恢复提示词、参数、参考图和结果图。
- 左栏拖拽期间只更新前端布局状态，不写入数据库。
- 生成、分析、取消、上传、下载和历史恢复逻辑保持不变。

## 测试与验证

- 组件测试验证接口配置默认折叠、展开后字段可见。
- 组件测试验证历史记录不在左栏，历史按钮可打开和关闭右侧抽屉。
- 组件测试验证点击历史记录后恢复结果并关闭抽屉。
- 组件测试继续验证提供商名称不可见和计时使用两位小数秒数。
- 浏览器测试验证左栏拖拽限制在 `280–480px`，中央画布仍有可用宽度。
- 浏览器测试验证全屏图片的四条边均在视口内，且背景不是黑色。
- 浏览器测试验证桌面和移动端无横向溢出、无遮挡、无控制台错误。
- 运行完整前端测试和 Vite 生产构建。
