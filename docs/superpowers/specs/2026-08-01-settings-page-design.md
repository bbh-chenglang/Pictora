# 独立设置页面设计

## 目标

将工作台顶部的“修改密码”入口改为“设置”，点击后进入独立 `/settings` 页面，集中管理用户 API Key 和密码。模型选择继续保留在工作台主页面，不移动到设置页。

## 页面结构

设置页沿用 GenImage 现有视觉风格，包含顶部导航和设置主体。

- 顶部提供“返回工作台”按钮。
- 顶部显示当前用户名和“退出登录”按钮。
- 主体包含三个设置区块：
  - 接口配置：API Key 输入、已配置状态、保存/清除操作。不显示模型选择。
  - 修改密码：旧密码、新密码、确认新密码和提交按钮。
  - 主题：亮色和暗色选项，但控件禁用并显示暂不支持，不保存、不改变页面主题。

## 路由与状态

- 工作台点击“设置”进入 `/settings`。
- 已登录用户访问 `/settings` 时加载 `/api/auth/me` 和当前设置状态。
- 未登录访问 `/settings` 跳转登录页。
- 返回工作台保留当前 Cookie 会话。
- 退出登录清理会话并跳转登录页。
- 修改密码成功后服务端撤销全部会话，前端跳转登录页。

## 数据与接口

继续使用已有接口：

- `GET /api/settings` 获取 API Key 是否已配置，不返回完整 API Key。
- `PUT /api/settings` 保存新 API Key；空值清除 API Key。
- `PUT /api/auth/password` 修改密码，要求旧密码、新密码和确认新密码。
- `POST /api/auth/logout` 退出登录。

不增加数据库表，不改变模型设置接口。主页面仍负责模型选择和自动保存。

## 测试

- 设置入口显示“设置”而不是“修改密码”。
- 点击设置进入设置视图，显示 API Key、修改密码和禁用主题选项。
- 设置页不显示模型选择。
- API Key 保存请求不包含模型变更，页面不显示完整 API Key。
- 修改密码请求包含旧密码、新密码和确认密码。
- 修改密码成功后回到登录页。
- 未登录访问设置页跳转登录页。
- 返回工作台后仍保持登录状态。
