# 提示词库“五百飘雪”主题统一设计

## 目标

将工作台的提示词选择弹窗与提示词管理页面统一为当前“五百飘雪”主题，移除遗留的暗色表面，同时保持原有数据、操作和信息密度不变。

## 视觉方向

- 页面与弹窗采用半透明白色表面，维持雪景背景的通透感。
- 边框、分隔线、聚焦态使用低饱和冰蓝。
- 主要按钮与高亮操作使用深蓝；正文使用深蓝灰，辅助文字使用中性灰蓝。
- 弹窗遮罩使用蓝灰透明层，保留背景可见性，避免旧样式的纯黑压暗效果。

## 覆盖范围

- `PromptPickerPopover`：提示词选择弹窗、分类筛选、空状态、底部操作。
- `PromptsView`：提示词管理页面的顶栏、筛选控件、提示词条目、空态、错误态及操作按钮。
- `PromptEditorDialog`：新增和编辑提示词弹窗及其输入控件。
- 提示词管理页触发的确认删除弹窗：确保删除流程不重新引入暗色表面。

## 实现边界

- 在提示词相关样式中使用统一的局部 CSS 自定义属性表达表面、边框、文字、操作色和遮罩色。
- 不改变组件对外接口、API 调用、筛选逻辑、新增编辑删除行为或中文文案。
- 不修改工作台其他区域的主题逻辑和背景特效。

## 验证

- 添加能够断言提示词模块不再含旧暗色令牌、且使用浅色主题令牌的前端测试。
- 运行前端测试与生产构建。
- 在浏览器中检查工作台的提示词选择、管理页加载与筛选、创建、编辑和删除确认状态的可读性及主题一致性。
