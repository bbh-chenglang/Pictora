# 技能广场分类筛选框雪白主题适配

## 目标

将技能广场工具栏中的“全部分类”选择框适配为雪白背景，消除当前深色背景与页面雪白主题的视觉冲突。

## 范围

- 仅调整 `frontend/src/components/SkillsView.vue` 中工具栏分类选择器的显示样式。
- 选择框和原生展开选项均使用白色背景与深色文字。
- 保留现有筛选行为、尺寸、焦点样式和创建技能对话框的深色选择器。

## 实现

为工具栏选择器增加独立 CSS 选择器，设置白色背景、近黑文字和中性浅灰边框；为其 `option` 元素显式指定白底深字。避免修改共享选择器，以防影响创建技能对话框。

## 验证

- 前端生产构建通过。
- 浏览器中确认“全部分类”收起状态为白底深字，展开选项也保持白底深字。
