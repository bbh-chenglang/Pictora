# 工作区拖拽分隔条显隐设计

## 目标

隐藏提示词输入区上方工作区分隔条的默认视觉边界，仅在用户将鼠标移入原有拖拽区域、通过键盘聚焦该控件，或正在拖拽时显示分隔线和现有控制柄。

## 方案

在 `frontend/src/App.vue` 的工作区分隔条样式中保留既有尺寸、指针事件、键盘事件和拖拽状态。默认态将可见轨道、边线与控制柄透明化；`:hover`、`:focus-visible` 以及 `workspace-is-resizing` 状态恢复当前视觉样式。

## 约束

- 不修改工作区高度比例、最小/最大边界或本地持久化逻辑。
- 不缩小可拖拽命中区域。
- 键盘访问分隔条时必须仍能获得可见焦点。
- 拖拽开始后，即使指针离开分隔条，也必须持续可见，直到拖拽结束。

## 验证

- 自动化样式/组件测试确认默认态为隐藏，悬停、焦点与拖拽态为可见。
- 浏览器检查确认鼠标拖拽和键盘调整仍正常工作。
